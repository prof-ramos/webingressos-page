# Marketing skills

Este repositório mantém cópias versionadas das skills necessárias para que agentes universais consigam trabalhar sem uma instalação inicial adicional:

- `product-marketing`;
- `copywriting`;
- referências utilizadas pela skill `copywriting`.

Origem: `coreyhaines31/marketingskills`.

Para atualizar as cópias a partir do projeto oficial:

```bash
pnpm skills:update
```

Revise o diff e preserve `.agents/product-marketing.md`, que contém o contexto específico da WebIngressos. Os arquivos de terceiros permanecem sujeitos à licença registrada em `THIRD_PARTY_LICENSES.md`.
